# User Interviews

## Interview 1

Name:
Anonymous student developer

Role:
Computer science student working on academic and side projects

AI tools used:
- ChatGPT
- Gemini
- cursor

Key quotes:
- "I mostly use ChatGPT and Gemini depending on what limits I hit."
- "I thought about paying mainly when file upload limits became annoying."
- "I don't really track how much I would spend on AI tools."

Most surprising insight:
The user switched frequently between free AI tools instead of committing to one paid platform.

What it changed about the product:
This reinforced the importance of helping users compare overlapping AI subscriptions and identify unnecessary tool duplication.

Potential value perception:
The user felt an AI spend audit tool could become useful once they started paying

## Interview 2

Name:
Anonymous student user

Role:
Student using AI tools for assignments and research

AI tools used:
- ChatGPT

Key quotes:
- "I mostly use ChatGPT for assignments and general content work."
- "I never really paid because the free version already covers most of my needs."
- "I would probably consider paying mainly for better file uploads, charts, and diagrams."
- "If a company or team paid for it, I would definitely use premium plans."

Most surprising insight:
The user cared more about convenience features like uploads and visual outputs than raw AI capability improvements.

What it changed about the product:
This highlighted that users evaluate AI subscriptions based on workflow convenience, not just model intelligence.

Potential value perception:
The user felt pricing comparison tools could become useful once AI subscriptions become part of regular team workflows.

## Interview 3

Name:
Anonymous student developer

Role:
Student preparing for internships and coding projects

AI tools used:
- ChatGPT
- Cursor

Key quotes:
- "I mainly use ChatGPT for debugging and Cursor while coding."
- "I usually pick whichever tool feels faster instead of comparing pricing."
- "Most students probably wouldn't track AI spending carefully unless they start paying monthly."
- "A dashboard comparing plans and savings would help once multiple subscriptions start stacking up."

Most surprising insight:
The user selected tools based more on workflow speed and convenience than model quality differences.

What it changed about the product:
This reinforced the idea that the audit experience should remain simple and visual rather than overly technical.

Potential value perception:
The user believed the tool would become more valuable for startup teams or developers managing multiple paid AI subscriptions.

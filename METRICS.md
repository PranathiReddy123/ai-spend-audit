# Product Metrics

## Primary KPI

- Completed audits per user session

## Secondary Metrics

- Average estimated savings generated
- Audit completion rate
- Results page engagement time
- CTA click-through rate

## Product Goals

- Reduce perceived AI software waste
- Increase visibility into subscription inefficiencies
- Provide actionable optimization recommendations

## North Star Metric

The primary North Star metric for this product is:

# Completed Audits Per Week

This metric best represents whether the product is successfully delivering value to users.

The audit itself is the core value moment:
- users input real spending data
- receive optimization insights
- identify potential savings

A completed audit signals:
- engagement
- trust
- product usefulness
- lead-generation opportunity

Unlike daily active users, this metric better matches the behavior of a B2B financial optimization tool that users may only use periodically.

---

# Input Metrics

## 1. Landing Page → Audit Start Conversion Rate

Tracks how effectively the homepage convinces visitors to begin an audit.

This helps measure:
- landing page clarity
- messaging quality
- CTA effectiveness

---

## 2. Audit Completion Rate

Measures how many users finish the full audit flow after starting it.

This indicates:
- UX quality
- form friction
- perceived product value

---

## 3. Consultation Request Rate

Measures how many high-savings users request additional help or Credex consultation.

This directly impacts:
- lead quality
- revenue generation
- business value

---

# First Instrumentation Priorities

The first analytics events I would track:
- homepage visits
- audit started
- audit completed
- results viewed
- consultation CTA clicks
- report export clicks

These events would provide visibility into:
- conversion drop-offs
- UX friction
- user intent quality

---

# Pivot Trigger

A major pivot would be considered if:
- audit completion rate falls below 25%
- users do not share or revisit audit results
- consultation request conversion remains extremely low

This would indicate either:
- insufficient value perception
- weak recommendation quality
- poor targeting of the intended audience

In that case, I would likely reposition the tool toward:
- benchmarking
- AI cost comparison reports
- team-level SaaS analytics
rather than direct lead generation.

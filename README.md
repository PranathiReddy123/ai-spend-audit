# AI Spend Audit

AI Spend Audit is a SaaS-style web application that helps startups and engineering teams analyze AI tooling costs and identify optimization opportunities.

The platform allows users to:
- analyze current AI software spending
- compare plan efficiency
- identify unnecessary enterprise/team subscriptions
- visualize spend analytics
- estimate annual savings opportunities

## Features

- Dynamic audit workflow
- AI tool pricing engine
- Spend analytics dashboard
- Optimization scoring
- Responsive SaaS UI
- Local state persistence
- Real-time spend calculations
- Chart-based analytics

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Recharts
- Vercel
- GitHub
